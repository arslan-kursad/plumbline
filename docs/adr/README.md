# Architecture Decision Records

One file per decision, named `ADR-NNNN-kebab-case-title.md`. Sections are fixed:
Context, Decision, Alternatives considered, Consequences, Enforcement — the last
naming which controls prevent a violation and which only report it. An ADR is
immutable once Accepted; a changed decision is a new ADR that supersedes it, and
both files record the link.

The index with current statuses lives in `docs/architecture.md` §10.
